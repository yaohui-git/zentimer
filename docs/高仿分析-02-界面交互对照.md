## 3. 声音：从「11 段」补到「原版同款」

原版 `assets/flutter_assets/assets/timer/sounds/` 共 **30 段 mp3**，REA 全量清点 + craft 内容对比确认。

| 类别 | 原版 | v2.0 | v2.1 |
| --- | --- | --- | --- |
| 颂钵实物录音 | `bell_{basu,dengze,kangse,ombu,sakya,shurong,zhada,gong,wood_block}.mp3` = **9** | 8（**漏 zhada**） | **9** |
| 静音轨 / 提示音 | `silent.mp3`、`notify.mp3` | 0 | 2（静音可选，提示音入库备用） |
| 环境音（自然） | `b1-*` 7 + `crystal-rain_rain-drops` + `b1-ocean-wave` + `golden_om_deep-om` | 3 | **10** |
| 器乐环境音 | `dbs_03/19/31` 3 | 0 | **3** |
| 音乐床 | `b2-*` 7 | 0 | ⬜ **不取**：偏内容曲库，不是环境音 |
| 合计 | 30 | 11 | **23**（含静音/提示） |

**字节级一致性**：craft `core-archives-compare` 把 v2.0 的 11 段 mp3 判为 `moved`（从原版 `assets/.../sounds/` 到 `res/raw/`，sha256 相同），不是 `changed` —— 说明音频一个字节都没改。v2.1 新增的 12 段同样原样复制。

## 5. 仍然存在的差距（不掩饰）

1. **没有真机截图对比**。所有「高仿」判断基于原版交付物里的实物素材、组件声明、资源名与 demo 预览图；像素级相似度无法验证。
2. **未做 MediaSession 锁屏控制、背景音独立音量**。这两项在原版由 `MediaSessionService` / `SleepMixerForegroundService` 承担，但会引入 media3 与混音器依赖，与「功能简约、不冗余」冲突，属于**主动裁剪**，不是遗漏。
3. **b2 音乐床 7 段未取**。它是内容曲库而非环境音，同样按裁剪处理。
4. **通知权限未动态申请**。Android 13+ 若用户未授予通知权限，前台服务仍保活、铃声照响，但通知可能不在抽屉显示（服务在任务管理器可见）。这是为了不给一个离线工具加权限弹窗的取舍。
