## 7. 复现命令（换机也能重跑）

```bash
CLI="stilltimer/.craft/bin/craft-anything-0.3.0-windows-x64-portable/craft-anything-cli.exe"
PRJ="stilltimer/.craft/StillTimer.cany"
APK="<绝对路径>/base.apk"

"$CLI" doctor
"$CLI" --project "$PRJ" --deep core-target-triage        --path "$APK"
"$CLI" --project "$PRJ" --deep android-package-show       --path "$APK"
"$CLI" --project "$PRJ" --deep android-app-graph-build    --path "$APK"
"$CLI" --project "$PRJ" --deep android-resources-read     --path "$APK" --with-strings true
"$CLI" --project "$PRJ" --deep core-archives-compare      --left "$APK" --right "<v2.x.apk>"
"$CLI" --project "$PRJ" --deep core-evidence-export       --path "<...>/evidence-bundle.json"
```

REA 侧：`open_binary` → `inspect_artifact(detail=summary)` → `inspect_analysis_view(kind=inventory)`，证据 ID 见 `高仿分析-01-FEATURE-MAP.md` 第 0 节。
